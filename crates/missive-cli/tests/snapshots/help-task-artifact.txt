List, show, save, or export artifacts persisted for a task

Usage: missive task artifact [OPTIONS] <COMMAND>

Commands:
  list    List artifacts persisted for one local task
  show    Show one persisted artifact and its metadata/content summary
  save    Save one persisted artifact to a local file
  export  Export all persisted artifacts for one task into a directory

Options:
  -h, --help     Print help
  -V, --version  Print version
