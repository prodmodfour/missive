Run a local HTTP receiver for A2A push notification callbacks

Usage: missive webhook run [OPTIONS]

Options:
      --bind-address <IP>       IP address to bind. Defaults to the selected profile gateway bind address
      --port <PORT>             TCP port to bind. Defaults to the selected profile gateway bind port
      --path <PATH>             HTTP path that receives A2A StreamResponse push payloads [default: /a2a/push]
      --auth-header <HEADER>    Require callbacks to include this header when --auth-token-env is set [default: Authorization]
      --auth-scheme <SCHEME>    Auth scheme prefix expected before the token; use 'none' for a raw token [default: Bearer]
      --auth-token-env <ENV>    Read the expected inbound webhook token from this environment variable
      --max-events <N>          Stop gracefully after accepting this many valid push callbacks
      --max-body-bytes <BYTES>  Maximum callback request body size in bytes [default: 1048576]
  -h, --help                    Print help
  -V, --version                 Print version

Global options:
      --json                        Emit a single JSON document for command output when the command supports it
      --ndjson                      Emit newline-delimited JSON events when the command supports streaming output
  -q, --quiet                       Suppress non-error output
      --no-color                    Disable colored terminal output and diagnostics
      --config <PATH>               Read configuration from this file path
      --profile <PROFILE>           Select a named configuration profile
      --timeout <DURATION>          Set an overall command timeout such as 30s, 2m, or 1h
      --protocol-version <VERSION>  Override the A2A protocol version sent as the A2A-Version service parameter
      --a2a-extension <EXTENSION>   Request an A2A extension through the A2A-Extensions service parameter; repeatable
      --service-param <NAME=VALUE>  Add an arbitrary A2A service parameter as NAME=VALUE; repeatable
      --bearer-token-env <ENV>      Read a bearer token from this environment variable and send it as Authorization
      --header <NAME:VALUE>         Add an outbound HTTP header as Name:Value; repeatable and never persisted
      --trace                       Enable trace-oriented diagnostics for this invocation
  -v, --verbose...                  Increase human diagnostic verbosity; repeat for more detail
