Wait for tasks associated with every registered member of a local group and one shared A2A context to reach terminal states or explicitly requested states, optionally consuming a previous bcast JSON result for task ids.

Usage: missive barrier [OPTIONS] <GROUP>

Arguments:
  <GROUP>
          Local group name whose member tasks should be synchronized

Options:
      --context <CONTEXT_ID>
          A2A context id shared by the member tasks

      --from-bcast <PATH_OR_->
          Read a previous `missive bcast --json` result from this path, or '-' for stdin

      --state <STATE>
          State that counts as satisfying the barrier; repeatable.
          
          When omitted, the barrier waits for terminal states and succeeds only for completed tasks. Failed or cancelled member tasks produce deterministic non-zero exits unless a smaller quorum has already succeeded.

      --required <N>
          Number of member tasks that must satisfy the target states; defaults to every member

      --failure-policy <POLICY>
          Failure handling for member task failures or cancellations

          Possible values:
          - stop:     Stop as soon as a non-requested failed/cancelled terminal state is observed
          - continue: Continue polling until the requested quorum is reached, impossible, or timed out
          
          [default: stop]

      --local
          Poll only local SQLite task rows instead of refreshing remote A2A tasks

      --interval <DURATION>
          Poll interval such as 500ms, 2s, or 1m

      --history-length <N>
          Request this many history messages from remote A2A GetTask calls

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --json
          Emit a single JSON document for command output when the command supports it

      --ndjson
          Emit newline-delimited JSON events when the command supports streaming output

  -q, --quiet
          Suppress non-error output

      --no-color
          Disable colored terminal output and diagnostics

      --config <PATH>
          Read configuration from this file path

      --profile <PROFILE>
          Select a named configuration profile

      --timeout <DURATION>
          Set an overall command timeout such as 30s, 2m, or 1h

      --protocol-version <VERSION>
          Override the A2A protocol version sent as the A2A-Version service parameter

      --a2a-extension <EXTENSION>
          Request an A2A extension through the A2A-Extensions service parameter; repeatable

      --service-param <NAME=VALUE>
          Add an arbitrary A2A service parameter as NAME=VALUE; repeatable

      --bearer-token-env <ENV>
          Read a bearer token from this environment variable and send it as Authorization

      --header <NAME:VALUE>
          Add an outbound HTTP header as Name:Value; repeatable and never persisted

      --trace
          Enable trace-oriented diagnostics for this invocation

  -v, --verbose...
          Increase human diagnostic verbosity; repeat for more detail
