Explain a dry-run routing decision without sending a message

Usage: missive route explain [OPTIONS]

Options:
      --group <GROUP>            Use this stored group as the route candidate set
      --agent <ALIAS>            Use one registered agent as a route candidate; repeat for multiple candidates
      --policy <POLICY>          Override the group/config routing policy for this dry run
      --preferred-agent <ALIAS>  Preferred primary/direct agent. The alias must be in the candidate set
      --tag <TAG>                Required local or Agent Card skill tag for tag-match/capability-match explanations
      --capability <CAPABILITY>  Required local or Agent Card capability label for capability-match explanations; repeat for multiple labels
      --input-mode <MODE>        Required Agent Card input MIME/media mode for capability-match explanations
      --output-mode <MODE>       Required Agent Card output MIME/media mode for capability-match explanations
      --streaming                Require Agent Card streaming support for capability-match explanations
      --push-notifications       Require Agent Card push notification support for capability-match explanations [aliases: --push]
      --refresh-capabilities     Revalidate/fetch Agent Cards before extracting capability data
      --cursor <N>               Deterministic cursor for round-robin dry runs [default: 0]
      --quorum <N>               Required successful member count for quorum dry runs
  -h, --help                     Print help
  -V, --version                  Print version

Global options:
      --json                        Emit a single JSON document for command output when the command supports it
      --ndjson                      Emit newline-delimited JSON events when the command supports streaming output
  -q, --quiet                       Suppress non-error output
      --no-color                    Disable colored terminal output and diagnostics
      --config <PATH>               Read configuration from this file path
      --profile <PROFILE>           Select a named configuration profile
      --timeout <DURATION>          Set an overall command timeout such as 30s, 2m, or 1h
      --protocol-version <VERSION>  Override the A2A protocol version sent as the A2A-Version service parameter
      --a2a-extension <EXTENSION>   Request an A2A extension through the A2A-Extensions service parameter; repeatable
      --service-param <NAME=VALUE>  Add an arbitrary A2A service parameter as NAME=VALUE; repeatable
      --bearer-token-env <ENV>      Read a bearer token from this environment variable and send it as Authorization
      --header <NAME:VALUE>         Add an outbound HTTP header as Name:Value; repeatable and never persisted
      --trace                       Enable trace-oriented diagnostics for this invocation
  -v, --verbose...                  Increase human diagnostic verbosity; repeat for more detail
